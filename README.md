# E-Commerce Backend

This is an **E-Commerce Backend** project built using Java and Spring Boot. I created this project to practice backend development and understand how a real-world E-Commerce application works.

## Tech Stack

* Java 22
* Spring Boot
* Spring Data JPA & Hibernate
* Spring Security & JWT
* MySQL
* Maven
* REST APIs
* ModelMapper
* Swagger

## Features

* User registration and login
* JWT-based authentication
* Product and category management
* Shopping cart
* Order management
* Address management
* Payment integration
* Exception handling and validation

## Database

The project uses **MySQL**.

Create the database:

```sql
CREATE DATABASE ecommerce;
```

Then configure the database details in `application.properties`.

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure MySQL.
4. Run `SbEcomApplication.java`.

The application runs on:

```text
http://localhost:8080
```
